# NIVY - Sistema experto

## Ejecutar

Desde la carpeta raíz:

```bash
python main.py
```

## Ejecutar pruebas

```bash
python -m unittest discover -s tests -v
```

## Configurar la playlist

Abre:

`conocimiento/reglas.json`

Busca:

`playlist_musica`

y reemplaza la URL de ejemplo por la URL real de tu playlist de YouTube.

Una URL de playlist de YouTube tiene normalmente el formato:

`https://www.youtube.com/playlist?list=PLI1yT-YHTPFY&index=1`
